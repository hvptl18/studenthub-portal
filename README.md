# StudentHub Portal

StudentHub is a centralized student portal designed to bring academic, campus, and student activities into one platform.

## Problem Statement

Students often depend on multiple platforms for assignments, attendance, resources, events, clubs, and announcements.

StudentHub solves this problem by providing a unified platform for students.

## Features

- Student login
- Student dashboard
- Course management
- Assignment tracking
- Attendance monitoring
- Study resources
- Campus events
- Student clubs
- Announcements
- Student profile

## User Roles

### Student
- View courses
- Track assignments
- View attendance
- Access resources
- Register for events
- Join clubs

### Faculty
- Upload resources
- Create assignments
- Post announcements

### Admin
- Manage students
- Manage courses
- Manage events
- Manage clubs
